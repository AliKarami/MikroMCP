# docs.mikromcp.com (Starlight) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a Starlight documentation site at `docs-site/` that renders the existing 15 `docs/wiki/*.md` pages (transformed at build time), themed to match the landing page, with a deploy guide for nginx + Cloudflare.

**Architecture:** A standalone Astro + Starlight project in `docs-site/`. A `prebuild` Node script (`scripts/sync-wiki.mjs`) reads `../docs/wiki/*.md`, adds Starlight frontmatter (title from the leading `# H1`, which it strips), rewrites wiki-style links to root-relative routes, and writes into the git-ignored `src/content/docs/`. Starlight config supplies sidebar, search, cross-nav; a `custom.css` overrides Starlight's CSS variables to the dark teal/orange brand. Output is static `dist/` for nginx.

**Tech Stack:** Astro 6, `@astrojs/starlight` 0.39.x, vanilla Node (ESM) for the sync script, Starlight built-ins (Pagefind search, sitemap, Shiki). Reference spec: `docs/superpowers/specs/2026-06-02-docs-site-design.md`.

- [ ] **Step 3: Implement the helpers + frontmatter logic in `sync-wiki.mjs`**

```js
import { readFileSync, writeFileSync, readdirSync, mkdirSync, rmSync } from "node:fs";
import { dirname, resolve, basename } from "node:path";
import { fileURLToPath } from "node:url";

const __dirname = dirname(fileURLToPath(import.meta.url));
const WIKI_DIR = resolve(__dirname, "../../docs/wiki");
const OUT_DIR = resolve(__dirname, "../src/content/docs");

// Sidebar/order is driven by astro.config; here we only need a stable order number.
// Map of wiki file basenames (without .md) — order mirrors Home.md groupings.
export const WIKI_ORDER = [
  "Home",
  "Getting-Started",
  "RouterOS-API-Setup",
  "Configuration",
  "Running",
  "Connecting-to-Claude-Desktop",
  "Connecting-to-AI-Assistants",
  "Using-the-Skill",
  "Available-Tools",
  "Architecture",
  "Error-Handling",
  "Security",
  "Development",
  "Contributing",
  "Roadmap",
];

export function slugForWikiName(name) {
  if (name === "Home") return "";
  return name.toLowerCase();
}

export function extractTitle(body, fallbackName = "") {
  const m = body.match(/^#\s+(.+?)\s*$/m);
  if (m) return m[1].trim();
  return fallbackName.replace(/-/g, " ").trim();
}

function yamlTitle(title) {
  // Quote if the YAML value would be ambiguous (contains : # etc.)
  return /[:#]/.test(title) ? `"${title.replace(/"/g, '\\"')}"` : title;
}

export function transform(body, title, order, rewriteLinks = (s) => s) {
  // Strip the first H1 line (Starlight renders its own title)
  const withoutH1 = body.replace(/^#\s+.+?\s*$/m, "").replace(/^\n+/, "");
  const rewritten = rewriteLinks(withoutH1);
  const fm = `---\ntitle: ${yamlTitle(title)}\nsidebar:\n  order: ${order}\n---\n\n`;
  return fm + rewritten;
}
```

(The `rewriteLinks` argument defaults to identity here; Task 3 implements and wires the real rewriter. The runnable `sync()` entrypoint is added in Task 3 Step 3 so the file has a single `main` block.)

- [ ] **Step 3: Implement `rewriteWikiLinks` and the `sync()` entrypoint**

Add to `docs-site/scripts/sync-wiki.mjs`:

```js
const WIKI_NAMES = new Set(WIKI_ORDER);

function routeForWikiName(name) {
  if (name === "Home") return "/";
  return `/${name.toLowerCase()}/`;
}

export function rewriteWikiLinks(text) {
  // Match markdown links whose target is a bare wiki name with optional #anchor:
  //   ](Architecture)  ](Getting-Started#anchor)
  // Only rewrite when the name is a known wiki page; leave everything else alone.
  return text.replace(/\]\(([A-Za-z][A-Za-z0-9-]*)(#[^)]+)?\)/g, (full, name, anchor) => {
    if (!WIKI_NAMES.has(name)) return full;
    const route = routeForWikiName(name);
    if (name === "Home") {
      return anchor ? `](/${anchor})` : `](/)`;
    }
    return anchor ? `](${route}${anchor})` : `](${route})`;
  });
}

function sync() {
  rmSync(OUT_DIR, { recursive: true, force: true });
  mkdirSync(OUT_DIR, { recursive: true });
  const files = readdirSync(WIKI_DIR).filter((f) => f.endsWith(".md"));
  let count = 0;
  for (const file of files) {
    const name = basename(file, ".md");
    const order = WIKI_ORDER.indexOf(name);
    const safeOrder = order === -1 ? 99 : order;
    const raw = readFileSync(resolve(WIKI_DIR, file), "utf8");
    const title = extractTitle(raw, name);
    const out = transform(raw, title, safeOrder, rewriteWikiLinks);
    const slug = slugForWikiName(name);
    const outName = slug === "" ? "index.md" : `${slug}.md`;
    writeFileSync(resolve(OUT_DIR, outName), out, "utf8");
    count++;
  }
  console.log(`[sync-wiki] wrote ${count} pages to src/content/docs/`);
}

// Run when invoked directly (node scripts/sync-wiki.mjs), not when imported.
if (import.meta.url === `file://${process.argv[1]}`) {
  sync();
}
```
